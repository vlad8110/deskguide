# Resource evaluation

Start with existing computers and a zero-dollar software/API budget. Flask, SQLite, and local retrieval do not require a paid service. Select one generation option after testing; do not implement every provider.

The team review document contains the researched shortlist: Cohere evaluation API, GroqCloud free tier, eligible Gemini free models, Cloudflare Workers AI free allocation, Azure for Students credits, Hugging Face inference credits, and local Ollama. These differ in eligibility, quotas, privacy, permitted use, and hardware requirements. Verify current provider terms and actual account limits before selection.

Compare supported and unsupported questions, citation support, speed, failure handling, and the classroom demonstration requirements. Public hosting and persistent storage need separate evaluation. No paid provider or API account has been activated through this setup.
